Bugs this verification found, none of which would have surfaced from reading
the code:

  * All four model ids in .env were DISPLAY NAMES, not API ids
    ("Gemini 3.6 Flash", "Llama 3.3 70B", "glm-5.3[1m]", "qwen3.6-27b").
    Every provider failed with HTTP 400/404 - which looks exactly like a bad
    key until you read the response body. The keys were fine all along.

  * Current models are REASONING models. gemini-3.6-flash spent 104 tokens
    thinking before writing anything, so max_tokens=1024 returned completely
    EMPTY content with finishReason=MAX_TOKENS and no error. Groq's qwen
    returns its reasoning inline in <think> tags. Both are now handled;
    max_tokens floors at 1024 and defaults to 2048.

  * GLM's paid models (glm-4.6, glm-5, glm-5.3) return HTTP 429 code 1113 -
    the account has no balance. glm-4.5-flash works on the free tier.

  * GLM takes ~21.7s per call. It works, but it can never lead the chain.
