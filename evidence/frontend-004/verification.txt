=== What testing found that reading would not have =======================
- **Empty-state strings double as loading states.** "No drafts" / "Nothing
  pending" render while the fetch is still in flight (units === null), so a
  wait keyed on them resolves against a transient frame and the action runs
  into a page with no buttons. Waits must target the BUTTON (or a data-only
  marker), never an empty-state sentence.
- **`textContent.trim() === "Approve"` never matches** — Material Symbols
  ligatures put their name inside the button ("check_circleApprove").
  `includes()` or an aria-label, not exact text equality.
- **A heredoc still eats Windows backslashes** (screenshot path mangled
  mid-run); forward slashes in JS paths, always.
- Remote-DB RTT means every wait needs ~2-4s of headroom over instinct;
  three "failures" today were fixed sleeps outrunning the data.
