  THE BANDS OVERLAP. 'Django project file structure' vs 'Django project
  settings' scores 0.7970 -- HIGHER than the 0.7829 between two genuine
  restatements of the virtual-environments concept. There is no threshold that
  merges the duplicates without also merging two different concepts.

  This is the same shape as ALIGNMENT_REFUSAL_THRESHOLD, and it gets the same
  answer the repo already settled on for that: similarity is a cheap FIRST
  gate, and a model call decides. MERGE_CANDIDATE is set to 0.75 -- below the
  0.7829 floor of true restatements, so no duplicate is gated out -- and every
  pair above it is decided by one call to prompts/concepts_same.md.

  Cost of the gate: 6 of 55 pairs here, so the decider runs rarely.
