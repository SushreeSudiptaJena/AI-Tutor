=== What building this found ==============================================
- **CourseTeacher had no `user` relationship** — the unit-test fake supplied
  one, so the suite passed while the live route 500'd on ct.user. A fake
  that fills in a missing relationship hides exactly the bug it should
  catch; the live smoke is what caught it.
- **create_batch never set batch.department**, only department_id, so
  _batch_out crashed reading department.name until the relationship was
  assigned at construction.
- Windows curl cannot read a git-bash /tmp path (HTTP 000, no server-side
  trace) — upload tests must use a repo-relative file.
- Nav labels carry their Material Symbols ligature
  ("account_treeSubjects & Materials"), so exact-match selectors fail. Same
  trap as frontend-004's "check_circleApprove".
