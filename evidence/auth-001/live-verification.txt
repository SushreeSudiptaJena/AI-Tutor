   plaintext present in the row? False
   (test account removed)

RESULT: PASS - all five verification steps in feature_list.json

  1. signup stores pbkdf2_sha256, never plaintext        step 9, 11
  2. correct password -> token                           step 2, 10
  3. wrong password -> 401, no token                     step 1
  4. protected route works with a token, 401 without     step 3, 4
  5. logout invalidates the token                        step 7, 8

Also covered beyond the spec:
  - duplicate email -> 409 conflict                      step 6
  - unknown email and wrong password return the SAME message, so the endpoint
    is not an account-enumeration oracle
  - every error uses the contract envelope {"error":{code,message,detail}}
  - the token is 64 hex chars with no dots: opaque, not a JWT
  - /auth/me never returns password_hash
