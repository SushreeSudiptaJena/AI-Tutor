  --- answer ---
To start a thread you need the POSIX thread library. First include its header:

```c
#include <pthread.h>
```

Then write the routine the thread will run. It must return `void *` and accept a single `void *` argument:

```c
void *runThread(void *arg) {
    printf("Running Thread\n");
    for (int i = 1; i <= 5; ++i)
        printf("%d\n", i);
    return NULL;                     // [1]
}
```

In `main` declare a variable of type `pthread_t` to hold the thread’s identifier:

```c
pthread_t tid;                       // [1]
```

Create the thread with `pthread_create`. The second argument (`NULL`) tells the system to use default attributes, the third argument is the function name, and the fourth is the argument you want to pass (here `NULL`):

```c
pthread_create(&tid, NULL, runThread, NULL);   // [1]
```

If you want the main program to wait for the thread to finish, call `pthread_join` with the same identifier:

```c
pthread_join(tid, NULL);             // [1][2]
```

Compile the source with the pthread library linked:

```bash
gcc createthread.c -o createthread -pthread   // [2]
```

Running the resulting executable will show the main message, the numbers printed by the thread, and finally “Thread over”. The same pattern works for multiple threads—just declare additional `pthread_t` variables and call `pthread_create` for each, then `pthread_join` each one, as illustrated in the textbook’s multi‑thread example. [3]
